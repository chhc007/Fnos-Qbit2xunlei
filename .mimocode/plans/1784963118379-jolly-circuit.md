# Plan: Fix Xunlei Download Submission (HTTP 400 Bad Request)

## Problem Analysis

The script crashes with `HTTP Error 400: Bad Request` when submitting download tasks to Xunlei. The root cause is that **our request body is missing many required fields** that the Xunlei API expects.

### Comparison: Browser Request (works) vs Our Code (fails)

**Browser request body (SUCCESS):**
```json
{
  "type": "user#download-url",
  "name": "【高清影视之家发布 www.BBEGGE.com】爱无退路...",
  "file_name": "【高清影视之家发布 www.BBEGGE.com】爱无退路...",
  "file_size": "14162396334",
  "space": "device_id#8d842bc20de9d63e49eb0cc7ebaea16e",
  "params": {
    "target": "device_id#8d842bc20de9d63e49eb0cc7ebaea16e",
    "url": "magnet:?xt=urn:btih:...",
    "total_file_count": "4",
    "parent_folder_id": "84341e2b0d2ab34842dd014c8c144f6d",
    "parent_folder_path": "/vol5/1000/影视库/下载/迅雷下载影视/电视剧/国产剧/",
    "sub_file_index": "0-3",
    "mime_type": "",
    "file_id": ""
  }
}
```

**Our code request body (FAILS with 400):**
```json
{
  "type": "user#download-url",
  "name": "",
  "params": {
    "url": "magnet:?xt=urn:btih:...",
    "target_dir": "/存储空间5/shield的文件/影视库/下载/迅雷下载影视"
  }
}
```

### Missing Fields (root cause of 400)

| Field | Browser | Our Code | Issue |
|-------|---------|----------|-------|
| `name` | torrent name | `""` (empty) | Missing |
| `file_name` | torrent name | not sent | Missing |
| `file_size` | `"14162396334"` | not sent | Missing |
| `space` | device_id | not sent | Missing |
| `params.target` | device_id | not sent | Missing |
| `params.target_dir` | N/A | wrong key | Should be `target` with device_id |
| `params.total_file_count` | `"4"` | not sent | Missing |
| `params.parent_folder_id` | folder hash | not sent | Missing |
| `params.parent_folder_path` | actual path | not sent | Missing |
| `params.sub_file_index` | `"0-3"` | not sent | Missing |
| `params.mime_type` | `""` | not sent | Missing |
| `params.file_id` | `""` | not sent | Missing |

### Additional Issues Found

1. **`_test_nas_cookie()` missing `XLA_CI` cookie** (`xunlei_downloader.py:186`) — should include `XLA_CI` like the browser does
2. **`_test_pan_auth()` sends empty `XLA_CI`** (`xunlei_downloader.py:209`) — hardcoded `XLA_CI=` instead of using `self.xla_ci`
3. **`xla_ci` not set during re-authentication** — when `init()` re-authenticates via WebSocket, it never extracts `xla_ci`
4. **`xunlei_api.py` uses hardcoded globals in `_ws_login`** (lines 133-134) — uses `NAS_HOST`/`NAS_PORT` instead of `self.*`
5. **Dockerfile missing `websockets` dependency** — only `requests` is installed
6. **`xunlei_api.py` `add_task()` uses wrong endpoint** — `/drive/v1/tasks` (plural) vs correct `/drive/v1/task` (singular)

## Implementation Plan

### Step 1: Fix `xunlei_downloader.py` — `add_download()` method

**File:** `xunlei_downloader.py`, lines 272-304

**Changes:**
1. Add all missing fields to the request body to match what the browser sends
2. Add a new method `_get_download_paths()` to query `device/download_paths` for folder_id
3. Map `XUNLEI_DOWNLOAD_PATH` config to the correct `parent_folder_id` and `parent_folder_path`
4. Parse the magnet link to extract `file_size` info (from `xl=` parameter in magnet URL, which is the torrent size)
5. Include `space`, `name`, `file_name`, `file_size`, `params.target`, `params.parent_folder_id`, `params.parent_folder_path`, `params.sub_file_index`, `params.mime_type`, `params.file_id` in the body

**New body structure:**
```python
body = {
    "type": "user#download-url",
    "name": name,           # torrent name (parsed from magnet or passed in)
    "file_name": name,      # same as name
    "file_size": file_size, # from xl= param in magnet, or "0"
    "space": self.device_space,
    "params": {
        "target": self.device_space,
        "url": url,
        "total_file_count": "0",
        "parent_folder_id": folder_id,       # from download_paths API
        "parent_folder_path": folder_path,   # from download_paths API
        "sub_file_index": "0",
        "mime_type": "",
        "file_id": "",
    },
}
```

### Step 2: Add `_get_download_paths()` method

**File:** `xunlei_downloader.py`

Add a new method that calls `GET /device/download_paths` (as seen in the browser requests) to get the list of available download folders with their `file_id` (folder_id). Then match the configured `XUNLEI_DOWNLOAD_PATH` to the correct folder.

### Step 3: Fix authentication issues

**File:** `xunlei_downloader.py`

1. **`_test_nas_cookie()`** (line 186): Add `XLA_CI` to the Cookie header
2. **`_test_pan_auth()`** (line 209): Use `self.xla_ci` instead of hardcoded empty string
3. **`init()`**: After WebSocket login, extract `xla_ci` from the credentials or set a default

### Step 4: Fix `xunlei_api.py`

**File:** `xunlei_api.py`

1. **`add_task()`** (line 315): Change endpoint from `/drive/v1/tasks` to `/drive/v1/task`
2. **`add_task()`** body: Add all missing fields (same as Step 1)
3. **`_ws_login()`** (lines 133-134): Use `self.nas_host`/`self.nas_port` instead of hardcoded globals

### Step 5: Fix Dockerfile

**File:** `Dockerfile`

Add `websockets` to the pip install line:
```
RUN pip install --no-cache-dir requests websockets
```

### Step 6: Add `.gitignore`

**File:** `.gitignore` (new)

Add entries for sensitive files:
```
config.ini
xunlei_data/
__pycache__/
```
